# Slide Map Bridge (QGIS 플러그인)

QGIS 조판(인쇄 레이아웃)과 PowerPoint 슬라이드를 연결합니다. Windows + Microsoft PowerPoint + QGIS 3.22 이상.

## 설치
```
qgis-plugin\install.cmd
```
QGIS → 플러그인 → 플러그인 관리 및 설치 → 설치됨 → **Slide Map Bridge** 체크. (외부 패키지 불필요)

## 작업 흐름
1. **슬라이드 → 조판** (메뉴 플러그인 ▸ Slide Map, 또는 툴바)
   PowerPoint에 열려 있는 프레젠테이션/슬라이드를 고르거나 .pptx 파일을 선택합니다.
   슬라이드 크기와 같은 조판이 생기고, 아래 순서로 쌓입니다.
   - `슬라이드 배경` : Slide Map 객체를 숨긴 슬라이드 이미지 (잠금)
   - `지도` : QGIS 지도 (Slide Map 프레임 위치·크기, 현재 캔버스 범위)
   - `슬라이드 오버레이` : 지도 **위**에 올라가는 카드·제목 등 (투명 PNG, 잠금)
   → 카드가 지도를 얼마나 가리는지, 선 굵기·글자 크기가 슬라이드에서 어떻게 보이는지 바로 판단할 수 있습니다.
   슬라이드가 바뀌면 디자이너의 `슬라이드 이미지 새로고침`을 누릅니다 (지도 항목은 유지).
2. 조판에서 스타일·범위·축척을 다듬습니다 (지도 항목을 움직이거나 크기를 바꿔도 됩니다).
3. **조판 → 슬라이드** (조판 디자이너의 Slide Map 메뉴/툴바)
   지도 항목만 PNG(기본 300dpi) 또는 SVG로 내보내 슬라이드의 프레임 위치에 삽입합니다.
   - 이름 `SlideMap · QGIS · <조판 이름>`, 태그 `SLIDEMAP_PART=qgis`, `SLIDEMAP_MAP=<mapId>`
   - 같은 조판에서 보낸 이전 결과는 교체되며, 같은 지도의 basemap 바로 위에 놓입니다.
4. **레이어 내보내기**: 선택/보이는 벡터 레이어를 EPSG:4326 GeoPackage 또는 GeoJSON으로 저장 → Slide Map 패널에 끌어다 놓기.

## 동작 방식과 한계
- **PowerPoint가 실행 중이어야 합니다.** 모든 PowerPoint 연동은 PowerShell COM(`ppt_ops.ps1`)으로 실행 중인 PowerPoint를 제어합니다. 실행 중이 아니면 목록/가져오기/보내기가 모두 "PowerPoint가 실행 중이 아닙니다"로 실패합니다. (`pptx_reader.py` 는 PowerPoint 없이 .pptx 의 슬라이드 목록/프레임만 읽는 보조 모듈로, 현재 플러그인 화면에서는 쓰이지 않고 테스트에서만 사용합니다. 이미지는 만들 수 없습니다.)
- **사용자의 프레젠테이션은 내보내기 때문에 바뀌지 않습니다.** 슬라이드 이미지는 `SaveCopyAs` 임시 사본을 창 없이 열어 그 사본에서만 객체 숨김/배경 변경 후 내보내고, 저장 없이 닫은 뒤 임시 파일을 지웁니다. 원본의 배경(그라데이션/그림 포함), 도형 가시성, 저장 여부 표시는 그대로입니다. 비정상 종료로 남은 사본은 다음 내보내기 때 정리됩니다.
- 닫혀 있는 .pptx는 읽기 전용·창 없이 열어 읽고 닫습니다. 슬라이드로 보낼 때만 PowerPoint 창에서 엽니다. OneDrive/SharePoint 문서(https 주소)는 PowerPoint에 열려 있어야 합니다.
- 슬라이드 ID가 있으면 ID로만 찾고, 없으면(삭제됨) 오류로 알립니다 (엉뚱한 슬라이드를 건드리지 않음).
- 슬라이드로 보낼 때 새 그림을 먼저 넣고 성공한 뒤에 이전 결과를 지웁니다. 교체 키는 조판의 고유 ID(`slidemap/qgis_id`, 태그 `SLIDEMAP_QGIS_ID`)라 조판 이름을 바꿔도 교체됩니다 (태그 없는 구버전 결과는 조판 이름으로 인식). "삽입 후 저장"은 읽기 전용/저장된 적 없는 문서에서는 건너뛰고 경고로만 알립니다.
- 지도 항목이 회전되어 있거나 첫 페이지 밖에 있으면 보내기를 거부합니다. 조판의 첫 페이지만 내보냅니다.
- 느린 PowerPoint 작업은 QGIS 작업 관리자(QgsTask)에서 백그라운드로 실행되어 QGIS가 멈추지 않으며 취소할 수 있습니다 (슬라이드 삽입 단계는 중간 취소 불가). 응답 제한시간은 60초입니다. 목록 조회 때 슬라이드별 도형 정보도 함께 읽으므로 슬라이드를 고를 때 추가 호출이 없습니다.
- 오버레이 투명도: PowerPoint PNG 내보내기는 배경을 채우므로, (사본에서) 배경을 검정/흰색으로 바꿔 두 번 내보낸 뒤 알파를 복원합니다. 마스터/레이아웃 도형은 지도 뒤에 있으므로 오버레이에서 제외됩니다. 해상도 배율 상한은 4배입니다.
- 슬라이드 이미지는 PowerPoint 렌더링 결과라 글꼴은 PowerPoint에 설치된 것이 쓰입니다. QGIS 라벨 글꼴은 QGIS에 설치돼 있어야 슬라이드와 같게 보입니다.
- 레이어 내보내기: 기본 저장 폴더는 `<pptx 폴더 또는 프로젝트 폴더>\slidemap-layers`이며 기존 파일은 덮어쓰지 않고 `_2`, `_3` … 번호를 붙입니다.
- Windows 전용. 캐시: `%LOCALAPPDATA%\SlideMapBridge\cache` (조판이 이 이미지를 참조하므로 지우면 배경이 비어 보임 → 새로고침. 새로고침에 성공하면 이전 캐시 폴더는 자동 삭제됩니다).
